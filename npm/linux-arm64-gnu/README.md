# @bfc-node/linux-arm64-gnu

Prebuilt native addon for linux arm64 (glibc), used by [`@bfc-node/core`](https://www.npmjs.com/package/@bfc-node/core).

You do not need to install this package directly. `@bfc-node/core` lists it as an
optional dependency, and npm installs only the one matching your platform.
